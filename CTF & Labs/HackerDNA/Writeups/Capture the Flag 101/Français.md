## 1. Présentation du laboratoire

Learn-101 est le premier laboratoire d'introduction proposé par HackerDNA.

Il permet de découvrir le fonctionnement d'un environnement CTF (*Capture The Flag*) et d'apprendre à récupérer puis soumettre un premier flag.

Contrairement aux laboratoires d'exploitation avancés, Learn-101 ne nécessite aucune connaissance technique particulière, aucun terminal et aucun outil spécialisé.

L'objectif est simplement de comprendre le fonctionnement de la plateforme et le mécanisme de validation des flags.

## 2. Objectifs

Le laboratoire permet de :

- Comprendre le principe du Capture The Flag.
- Identifier le format d'un flag HackerDNA.
- Accéder à un fichier contenant un flag.
- Copier correctement le flag.
- Soumettre le flag sur la plateforme.
- Valider son premier challenge et gagner des XP.

## 3. Déroulement du laboratoire

### Étape 1 — Lancement du lab

Depuis la page Learn-101 :

1. Se connecter à HackerDNA.
2. Cliquer sur **Start Lab**.
3. Attendre le démarrage de l'environnement.
4. Récupérer l'adresse IP ou l'accès fourni par la plateforme.

Le laboratoire utilise une instance dédiée.

### Étape 2 — Exploration de la cible

Ouvrir l'environnement du laboratoire dans le navigateur.

Le but est de découvrir la ressource permettant d'accéder au flag.

Aucun scan réseau ni exploitation complexe n'est nécessaire.

### Étape 3 — Accès au flag

Cliquer sur le bouton :

**Access the Flag**

Cette action ouvre une page contenant directement le flag.

Le flag est généralement présenté sous la forme d'un UUID :

    xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

Il s'agit d'une chaîne composée de caractères hexadécimaux et de tirets.

### Étape 4 — Copie du flag

Sélectionner intégralement le flag affiché.

Points importants :

- Copier la totalité de la chaîne.
- Ne pas oublier les tirets.
- Ne pas ajouter d'espace.
- Ne pas modifier les caractères.

### Étape 5 — Soumission du flag

Retourner sur la page du laboratoire HackerDNA.

1. Localiser le champ de soumission.
2. Coller le flag copié.
3. Cliquer sur **Submit**.
4. Vérifier que la validation est acceptée.

La soumission correcte valide le challenge et attribue les XP correspondants.

## 4. Résultat

À la fin du laboratoire :

- Le premier flag est récupéré.
- Le challenge est validé.
- 50 XP sont obtenus.
- Le fonctionnement de la plateforme HackerDNA est compris.

## 5. Compétences acquises

| Compétence | Description |
|---|---|
| CTF | Compréhension du principe Capture The Flag |
| Flag | Identification d'un flag au format UUID |
| Navigation | Exploration d'un environnement HackerDNA |
| Soumission | Validation d'un flag sur la plateforme |
| Workflow | Compréhension du cycle challenge → flag → validation |

## 6. Conclusion

Learn-101 constitue une introduction simple et accessible à la cybersécurité pratique.

Il permet de découvrir le fonctionnement d'un laboratoire HackerDNA sans nécessiter de connaissances techniques préalables.

Ce premier exercice pose les bases nécessaires pour aborder ensuite des challenges plus avancés impliquant l'inspection du code source, les vulnérabilités web, l'authentification, les cookies ou encore l'élévation de privilèges.
