## 🔍 About the Project & Ownership

**WWOSDB (WorldWide Open Source DataBase)** is an initiative created and maintained by **CFRM (CYBER Department)**. It centralizes essential cybersecurity documentation into clean, searchable Markdown files. Instead of scattered notes across dozens of websites, this repository provides quick-access references for:
* Analyzing historical data breaches, ransomware campaigns, and zero-day exploits.
* Identifying network ports, services, and error codes during audits or troubleshooting.
* Mastering Kali Linux utilities and offensive/defensive security concepts.

---

## 🌐 Web Platform Status

An interactive **WWOSDB web application** is currently **in development** by the **CFRM** team. It will feature:

## 📂 Repository Structure & Direct Links

### 1. Threat Intelligence & Cyber History
* 📜 **[Historical Hacks (`Historical Hacks.md`)](./Historical%20Hacks.md)** — An extensive, reverse-chronological archive of major cyberattacks, data breaches, supply-chain compromises, and ransomware incidents worldwide.
* 🕰️ **[Historical Hacks — Antechronological (`Historical_Hacks_antechronologique.md`)](./Historical_Hacks_antechronologique.md)** — Complementary timeline dataset tracking major security events.

### 2. Technical Reference Catalogs
* 🐉 **[Kali Linux Tools Catalog (`kali-tools.md`)](./kali-tools.md)** — Categorized reference of Kali Linux tools (Network, Web, OSINT, Wireless, Forensics, Reverse Engineering, Post-Exploitation) with key flags and associated network ports.
* 🔌 **[Network Ports Reference (`Ports/ports.md`)](./Ports/ports.md)** — Complete breakdown of TCP/UDP port ranges (Well-Known `0–1023`, Registered `1024–49151`, Dynamic `49152–65535`), IANA assignments, and critical attack surfaces.
* ⚠️ **[Error Codes Catalog (`errors.md`)](./errors.md)** — Quick troubleshooting guide covering HTTP status codes (`100–599`), DNS `RCODE` values, POSIX socket errors, TLS/SSL handshake alerts, and browser network errors.

### 3. Courses, CTF & Labs
* 🧰 **[The Hacker's Toolkit (`CTF & Labs/HackerDNA/The hacker's toolkit.md`)](./CTF%20%26%20Labs/HackerDNA/The%20hacker's%20toolkit.md)** — Beginner-friendly cybersecurity course covering tool recognition, offensive vs. defensive dual-use, learning methodology, and a 120+ tool cheat sheet.

## ⚖️ Disclaimer & Ethical Use

All resources, tools, and methodologies documented in this repository are provided strictly for **educational purposes, authorized security auditing, personal labs, and Capture The Flag (CTF) training**.  

Unauthorized scanning, exploitation, or disruption of systems without explicit permission is illegal. Always ensure you have proper authorization before testing any target.
